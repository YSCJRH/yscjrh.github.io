# Notes Drafts

These note drafts are source material for the personal website.

They are intentionally short, working-stage documents rather than polished essays.

Current purpose:
- establish the first real Notes content in the repository
- keep note topics truthful and bounded
- give the homepage a credible next content layer without forcing premature publishing

Publishing rule:
- a draft can stay in the repository before it is linked from the homepage
- notes should be linked publicly only after a quick review for clarity and tone
- notes should not claim unpublished results, hidden collaboration, or unsupported evidence
