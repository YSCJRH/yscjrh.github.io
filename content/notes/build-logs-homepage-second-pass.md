# Build Logs
## Why The Homepage Needed A Second Pass

Status: published
Published: 2026-04-21

### EN

#### What the first version already solved

The first version solved the structure problem. It put Hero, Research, Build, Notes, and About on one page and made the overall identity coherent enough to read.

That mattered, because before a personal website can become persuasive, it first has to become legible.

#### Why a second pass became necessary

The next problem was not structure. It was credibility. The earlier version still carried some landing-page habits that made the site feel more polished than grounded.

For a researcher-builder homepage, that is the wrong balance. The public surface should feel calm, clear, and accurate to the amount of evidence that actually exists.

#### The practical adjustments

- Reduce the hero scale so the page introduces a person before it introduces an effect.
- Replace repeated teaser logic with a clearer directional structure.
- Turn project cards into evidence of working style instead of glossy repository summaries.
- Keep Notes as a deliberate thinking surface instead of a placeholder content bucket.
- Make GitHub the clearest current public entry without pretending there is already a full contact system.

#### The rule behind the redesign

Remove anything that looks more certain, louder, or more productized than the public evidence can support.

That rule remains useful beyond this page. It is also a good rule for project storytelling, note publishing, and how a long-term research identity becomes trustworthy in public.

### 中文

#### 第一版已经解决了什么

第一版解决了结构问题。它把 Hero、Research、Build、Notes 和 About 放在同一个页面中，让整体身份变得连贯、可读。

这一步很重要，因为个人网站在产生说服力之前，首先必须让访客看得明白。

#### 为什么需要第二次调整

接下来的问题不再是结构，而是可信度。前一版仍然带着一些 landing page 的惯性，使网站看起来更像经过包装的产品表面，而不是扎实的个人研究与构建主页。

对于研究者—构建者主页，这是不合适的平衡。公开页面应该冷静、清楚，并与当前真正存在的证据强度相匹配。

#### 实际调整

- 缩小 Hero 的尺度，让页面先介绍“人”，再介绍视觉效果。
- 用更清楚的方向结构替代重复的预告逻辑。
- 让项目卡片展示工作方式的证据，而不只是光滑的仓库摘要。
- 把 Notes 保持成有意组织的思考空间，而不是占位内容区。
- 让 GitHub 成为当前最明确的公开入口，而不假装已经具备完整的联系系统。

#### 这次调整背后的规则

删掉一切比现有公开证据显得更确定、更响亮或更“产品化”的内容。

这条规则并不只适用于首页。它同样适用于项目叙事、笔记发布，以及长期研究身份如何在公开环境中逐渐建立可信度。
