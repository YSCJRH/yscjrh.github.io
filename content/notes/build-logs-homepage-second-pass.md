# Build Logs
## Why The Homepage Needed A Second Pass

Status: draft build log

### EN

The first version of the homepage solved the structure problem. It established Hero, Research, Build, Notes, and About in one place, and it already looked coherent.

The second pass was about a different problem: credibility.

The earlier version still carried some landing-page habits that made the site feel more like a polished product surface than a mature personal research/build homepage. The main adjustments were:

- reduce the Hero scale so the page introduces a person before it introduces a visual effect
- replace repeated teaser logic with one compact direction panel
- turn Build cards from repository summaries into clearer evidence of working style
- keep Notes as a deliberate thinking surface instead of a placeholder content bucket
- make GitHub the clearest public action path without pretending there is already a fuller contact system

The guiding rule was simple: remove anything that looked more certain, louder, or more productized than the public evidence could support.

### 中文

首页第一版解决的是结构问题。它把 Hero、Research、Build、Notes 和 About 放到了同一张页面上，而且整体已经是连贯的。

第二次优化解决的是另一类问题：可信度。

前一版虽然已经成立，但仍然带着一些 landing page 的惯性，让页面更像一个打磨过的产品表面，而不是一个成熟的个人研究 / 构建主页。这一轮最关键的调整包括：

- 把 Hero 缩回来，让页面先介绍“人”，再介绍视觉效果
- 用一个更紧凑的方向面板替代重复预告逻辑
- 让 Build 卡片从仓库摘要转向工作方式与证据的展示
- 把 Notes 保持成一个有意保留的思考界面，而不是占位内容区
- 让 GitHub 成为最清楚的公开行动入口，而不是假装已经具备更完整的联系系统

这一轮背后的规则很简单：删掉一切比现有公开证据更确定、更响亮、也更“产品化”的部分。
